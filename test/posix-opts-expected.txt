# Open POSIX Test Suite dispositions. Same row schema and resolver as
# test/libc-test-expected.txt:
#
#   <case>  <profile selector>  <disposition>  <reason>
#
# Unlike libc-test-expected.txt, this file does NOT need one row per real
# case. It lists only the cases whose disposition deviates from PASS, plus
# one trailing wildcard row (case "*") that declares PASS as the suite's
# own default for every case with no more specific row. tools/testlib.py's
# resolve() falls back to a case="*" rule whenever a case-specific search
# comes up empty, so "everything else is PASS" is a real, matched rule
# here, not a hidden default argument in Python. Which cases are "real" --
# so that a case with no row here still gets adjudicated, rather than
# silently dropped -- comes independently from tools/posix-opts.py's own
# IFACES.rglob("*.c") discovery (see its resolved_policy()), not from what
# happens to be listed below.
#
# Baseline: spicule 3feb5cf, LTP 4c0cfb8, x86_64-win32-tcc, Wine,
# kernel32 disabled. These rules deliberately make no claim about another
# profile; add measured profile rules rather than copying these blindly.
#
# This environment has a working x86_64-win32-tcc but no runnable x86_64
# Wine; unless a row says otherwise, its non-PASS reason rests on
# compile/link evidence (and, where noted, a native aarch64-linux run of
# the unmodified upstream source), not an observed Wine run.
#
